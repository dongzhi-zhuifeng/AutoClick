# AutoClick

This repository uses Superpowers as **project-local** agent skills.

- Skills: `.cursor/skills/`
- MCP servers: `.cursor/mcp.json` (workspace only: `filesystem`, `command`)
- Session bootstrap: `.cursor/hooks.json` and `.cursor/rules/superpowers.mdc`

At session start, follow `.cursor/skills/using-superpowers/SKILL.md`. Do not install or change Superpowers in global Cursor settings or other projects.
